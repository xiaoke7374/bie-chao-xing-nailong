# 《别吵醒奶龙》代码规范

| 项 | 内容 |
| --- | --- |
| 版本 | v1.0 |
| 配套规则 | `.cursor/rules/coding-standards.mdc`（alwaysApply） |
| 栈 | Vite + TypeScript + Canvas 2D + HTML/CSS |

---

## 1. 总则

1. **可读优先于炫技**：小游戏以手感与状态清晰为第一。
2. **模块边界不可破**：规则层不碰 DOM/Audio；表现层不改分数/状态。
3. **配置外置**：手感参数进 `config.ts`，禁止魔法数散落在判定逻辑里。
4. **一次只做一个主视觉时刻**：壳层动效克制（对齐 frontend-design）。

---

## 2. 命名

| 类别 | 约定 | 例 |
| --- | --- | --- |
| 文件 | `camelCase.ts` 或与导出主类一致 | `stateMachine.ts` |
| 类型 / 接口 | `PascalCase` | `GameSnapshot` |
| 函数 / 变量 | `camelCase` | `warnIntensity` |
| 常量 | `UPPER_SNAKE` 或 `as const` 对象 | `DEFAULT_CONFIG` |
| 状态 ID | 与需求一致大写字面量 | `'SLEEP' \| 'WARN'` |
| CSS 变量 | `--kebab` | `--score-color` |
| CSS 类 | 短 BEM 或扁平前缀 `ui-` | `ui-hud`, `ui-result` |

中文仅用于文案与文档；**标识符用英文**。

---

## 3. TypeScript

- `strict: true`
- 禁止 `any`（必要时 `unknown` + 收窄）
- 公开模块导出明确 interface；内部实现可不导出
- 游戏循环用 `number` 毫秒；注释单位（`dtMs`）
- 不滥用 `enum`；优先字符串联合类型（与状态机一致）

```ts
// ✅
export type GameStateId = 'BOOT' | 'SLEEP' | 'WARN' | 'CATCH' | 'RESULT' | 'PAUSE'

// ❌
enum GameState { Boot, Sleep }
```

---

## 4. 架构落地约定

| 层 | 路径 | 允许 |
| --- | --- | --- |
| 配置 | `src/config.ts` | 纯数据 |
| 核心 | `src/core/*` | 无 DOM |
| 输入 | `src/input/*` | 读指针，产 `InputSnapshot` |
| 表现 | `src/presentation/*` | 订阅事件 / 读 snapshot |
| 皮肤 | `src/skins/*` | 实现 `SceneSkin` |
| 存储 | `src/storage/*` | 仅 localStorage 封装 |

**禁止**

- 在 `StateMachine` 内 `document.querySelector` / `AudioContext`
- 在 `Render` 内直接 `score +=`
- 为换皮肤复制一整份状态机

---

## 5. 主循环

固定顺序（与模块设计一致）：

1. `input.consume()`
2. `stateMachine.update(dt, input)`
3. `presentation.flush()`（若需要）
4. `render.draw(snapshot)` + `ui.sync(snapshot)`

- 使用 `requestAnimationFrame`；`dt` 做上限钳制（如 `Math.min(dt, 50)`）防切回爆帧
- `visibilitychange` 必须进入 `PAUSE`

---

## 6. HTML / CSS（壳层）

- 布局：游戏区 + HUD 叠加；竖屏优先，`100dvh` / `touch-action: none` 于操作区
- 设计 token 集中在 `:root`；先定 4–6 色再写组件
- **禁止默认 AI 壳**（除非 brief 点名）：紫靛渐变、三卡片栅格、奶油衬线+陶土色套餐、无意义 ALL-CAPS eyebrow
- 文案：极少字；按钮说清动作（「再来一次」）；句式统一
- `prefers-reduced-motion: reduce` 时弱化非惊吓必要动画；惊吓可保留极短替代反馈
- 选择器避免互相覆盖；少用标签选择器抢特异性

---

## 7. Canvas / 资源

- 逻辑坐标与 CSS 像素分离时，统一 `devicePixelRatio` 缩放
- 资源路径走 `public/` 或 import；失败要有兜底色块（灰盒可玩）
- 音效：首次手势后 `unlock`；静音只改 gain，不改判定

---

## 8. 文件与提交

- 单文件建议 < 400 行；状态机过大则拆 `transitions.ts`
- 不提交：密钥、`.taste-skill/` 缓存截图（若含本地绝对路径）、`node_modules/`
- 每次交付按仓库规则 **git commit**；信息说明 why

---

## 9. 注释与日志

- 不写废话注释；只注释「为什么」（宽限 180ms 的原因等）
- 开发期可用 `import.meta.env.DEV` 打日志；生产默认静默
- 禁止 `console.log` 留在抓捕热路径刷屏

---

## 10. 测试与验收（轻量）

MVP 不强制单测框架；必须可手工验收：

- T1–T10 见需求分析
- 改 `Config` 后回归：松手存活、峰内按住必死、再来一次清分留最高分
