---

## 1. 背景

MVP 已验证：按住偷吃 → 预警 → 被抓惊吓 → 再来。  
缺口（原 Should/Could）：

- 躲过预警缺少「心跳感」正反馈  
- 结算仅数字，不利于截图/转发  
- 连续博弈没有可见成长感  

本期聚焦 **传播与手感**，不做多场景、不做账号。

---

## 2. 本期功能范围

### 2.1 Must（本期必做）

| ID | 功能 | 说明 |
| --- | --- | --- |
| F1 | 惊险躲过（Near Miss） | 成功从 WARN 回到 SLEEP 时，给予短反馈（浮字+闪屏+音效） |
| F2 | 连躲连击（Dodge Streak） | 连续成功躲过预警次数；HUD 显示；被抓清零 |
| F3 | 结算分享卡 | 结算页可生成/下载成绩图（分数、最高分、连击峰值、是否新纪录） |
| F4 | 结算信息增强 | 展示本局最高连击；新纪录时有明确标识 |

### 2.2 Should（有余力）

| ID | 功能 |
| --- | --- |
| F5 | 连击 ≥3 时短暂得分倍率（如 ×1.2，仅 SLEEP 按住） |
| F6 | Web Share API（支持则唤起系统分享，否则下载图片） |

### 2.3 Won't（本期不做）

- 多场景皮肤、难度档位 UI、无惊吓模式、成就墙、排行榜服务端  

---

## 3. 用户故事

1. 作为玩家，我在预警时刚好松手躲过，希望感到「好险」而不是无事发生。  
2. 作为玩家，我想看到自己连续躲过了几次，激励继续赌。  
3. 作为玩家/创作者，我希望一键出成绩图，方便发朋友圈或短视频封面。  

---

## 4. 规则细节

### 4.1 惊险躲过触发

在 `WARN` 中满足任一且转入 `SLEEP`（未进 `CATCH`）：

- 预警自然结束且当时未按住；或  
- 在非抓捕窗口松手后回到睡眠；或  
- 在 peak 的 grace 内松手并最终存活  

**反馈（≤0.7s）**

- 浮字：「好险！」；若 `intensity` 曾 ≥ peakRatio →「太险了！」  
- 画面极短白/暖闪  
- 短促过关音（非惊吓音）  
- 可选轻微震动  

### 4.2 连击

- 每次成功躲过：`streak += 1`，更新 `maxStreak`（本局）  
- 进入 `CATCH`：`streak = 0`  
- 新局：`streak = 0`，`maxStreak = 0`  
- HUD：仅当 `streak ≥ 1` 显示 `连躲 ×N`  

### 4.3 分享卡内容

竖图（约 9:16 或 3:4），包含：

- 标题「别吵醒奶龙」  
- 本局分数、历史最高、本局最高连躲  
- 新纪录角标（若有）  
- 角色图（睡眠或惊吓小图，避免纯黑）  
- 无二维码硬性要求（MVP 无）  

操作：结算页按钮「分享成绩」→ 优先 Share，否则下载 PNG。

## 5. 验收标准

| 编号 | 用例 | 期望 |
| --- | --- | --- |
| V1 | WARN 中松手存活 | 出现「好险」类反馈，连击 +1 |
| V2 | 连续躲过 3 次 | HUD 显示连躲 ×3 |
| V3 | 被抓 | 连击归零；结算仍显示本局 maxStreak |
| V4 | 刷新最高分后结算 | 新纪录标识可见 |
| V5 | 点分享 | 得到可保存的成绩图 |
| V6 | 静音 | Near miss / UI 音均静音 |

---

## 6. 成功指标（定性）

- 躲过瞬间比 MVP 更想「再来一把」  
- 结算页停留时愿意点分享或截图  
- 不破坏原有 4 秒张力环与零文案上手
