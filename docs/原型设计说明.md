## 1. 设计计划（frontend-design）

### Color（4–6）

| Token | Hex | 用途 |
| --- | --- | --- |
| Night | `#14233A` | 夜厨底、手机壳 |
| Fridge | `#E8F4F8` | 冰箱冷光 |
| Nailong | `#F5D03A` | 角色/主按钮 |
| Belly | `#FFF6DE` | 亮面/纸感背景 |
| Warn | `#FFB020` | 将醒预警 |
| Scare | `#FF4D2E` | 被抓闪色 |

### Type

- **Fredoka**：标题、分数、主按钮（圆润玩具感）
- **Noto Sans SC**：中文说明与辅助信息

### Layout

- 竖屏 9:16 手机框为唯一构图单位
- 上 HUD（分/静音）→ 中角色+冰箱 → 下大热区
- 看板横滑五态；交互区可点状态机

### Principles

1. **角色即英雄**：惊吓用原图大笑扑脸，不另造恐怖符号  
2. **题材锚点**：夜 + 冰箱冷光 + 偷吃，不用 SaaS 紫渐变/三卡片  
3. **零长文案**：状态靠表情与光色；按钮只留「开始 / 再来一次」  
4. **一个主时刻**：CATCH 缩放扑镜，其它动效克制  

自检：未使用奶油衬线+陶土默认套、未用紫靛营销渐变、未做三列功能卡。

## 3. 如何打开

本地直接打开：

```text
prototype/index.html
```

或在项目根目录起静态服务后访问 `/prototype/`。

交互原型：左侧切状态；在 SLEEP/WARN 按住下方热区可看开门偷吃；WARN 仍按住会进 CATCH。
