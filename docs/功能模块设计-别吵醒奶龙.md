---

## 1. 设计目标

1. **单一核心**：所有模块服务于「按住偷做 → 预警 → 松手/被抓」循环。
2. **表现与规则分离**：状态机不依赖具体画风；换场景只换 Skin，不改判定。
3. **参数集中**：手感（预警间隔、宽限、得分速率）一处配置，便于打磨 4 秒张力环。
4. **网页轻量**：无后端；本地存储；单页可运行。

## 3. 分层与依赖规则

| 层 | 包含模块 | 允许依赖 |
| --- | --- | --- |
| L0 基础 | `Config`, `Storage` | 无业务模块 |
| L1 核心规则 | `StateMachine`, `WarnScheduler`, `Score`, `GameSession`, `Difficulty` | 仅 L0 |
| L2 输入输出 | `Input`, `UI`, `Audio`, `Render`, `SceneSkin` | L0 + 订阅 L1 事件 |
| L3 组装 | `App`, `Presentation` | 组装以上模块 |

**硬性约束**

- `StateMachine` **不得**直接调 DOM / Audio。
- `Render` / `Audio` **不得**改写分数或状态；只响应事件或只读快照。
- 换皮肤 = 换 `SceneSkin` 实现，不改 `StateMachine`。

## 4. 各模块详细设计

### 4.1 App（应用启动与主循环）

**职责**

- 创建 canvas/根节点，实例化各模块并接线
- `requestAnimationFrame` 驱动 `tick(dt)`
- `visibilitychange` → 进入/退出 `PAUSE`
- 首次用户手势通知 `Audio.unlock()`

**对外接口**

```ts
start(): void
stop(): void
tick(dtMs: number): void
```

**主循环顺序（固定）**

1. `Input.consume()`  
2. `StateMachine.update(dt, inputSnapshot)`  
3. `Score` / `WarnScheduler` 由状态机调用或同帧更新  
4. `Presentation.flush()`  
5. `Render.draw(snapshot)` + `UI.sync(snapshot)`  

---

### 4.2 Config（配置）

**职责**：集中手感与开关；支持运行时覆盖（调试面板可选）。

```ts
interface GameConfig {
  // 计分
  safeHoldScoreRate: number      // 分/秒，SLEEP 按住
  warnHoldScoreRate: number      // WARN 早期仍可缓慢加分，峰值期建议 0

  // 预警
  spawnWarnIntervalMin: number   // ms
  spawnWarnIntervalMax: number
  warnDuration: number           // 单次预警总时长 ms
  warnPeakRatio: number          // 0~1，后段视为危险峰
  catchGraceMs: number           // 进入峰后的反应宽限

  // 难度（Should）
  difficultyScoreStep: number    // 每涨多少分收紧一次
  intervalShrinkFactor: number
  durationShrinkFactor: number

  // 功能
  enableVibrate: boolean
  defaultMuted: boolean
}
```

**MVP 默认值建议**（实现时可再调）

| 键 | 建议初值 |
| --- | --- |
| `safeHoldScoreRate` | `25` |
| `warnDuration` | `1000` |
| `warnPeakRatio` | `0.55` |
| `catchGraceMs` | `180` |
| `spawnWarnIntervalMin/Max` | `1800` / `3200` |

### 4.3 Input（输入）

**职责**

- 将 mouse / touch 统一为 `isActing`（按住行动）
- 区分「游戏热区按住」与「UI 按钮点击」
- 阻止热区内页面滚动（`touch-action: none` + `preventDefault`）

```ts
interface InputSnapshot {
  isActing: boolean        // 当前是否按住行动
  actJustPressed: boolean
  actJustReleased: boolean
  uiAction: null | 'start' | 'retry' | 'toggleMute' | 'share'
}

interface InputModule {
  attach(root: HTMLElement, actZone: HTMLElement): void
  consume(): InputSnapshot
  resetEdges(): void
}
```

### 4.5 StateMachine（核心状态机）★

**状态**

`BOOT` → `SLEEP` ⇄ `WARN` → `CATCH` → `RESULT`；（任意进行中）⇄ `PAUSE`

```
                    start/retry
         ┌──────────────────────────┐
         ▼                          │
      [BOOT]──start──►[SLEEP]◄──松手且未抓──[WARN]
                         │                    │
                         │ 到点/调度           │ 峰内仍按住
                         ▼                    ▼
                       [WARN]──────────────►[CATCH]──►[RESULT]
                                                 ▲
                         切后台 ◄──► [PAUSE] 可从 SLEEP/WARN 进入
```

**转移表（权威）**

| From | Event / 条件 | To | 副作用 |
| --- | --- | --- | --- |
| BOOT | `uiAction=start` | SLEEP | `session.reset`，开始计时 |
| SLEEP | 调度器 `shouldWarn` | WARN | `warn.start()`，发 `warn:start` |
| SLEEP | `isActing` | SLEEP | 每帧 `score.add(rate*dt)` |
| WARN | `actJustReleased` 且未过抓捕判定 | SLEEP | `warn.end(survived)` |
| WARN | 进入 peak 且超过 grace 仍 `isActing` | CATCH | 锁定输入，发 `catch` |
| CATCH | 惊吓动画结束（时长配置） | RESULT | 提交最高分 |
| RESULT | `uiAction=retry` | SLEEP | `session.reset` |
| SLEEP/WARN | 页面隐藏 | PAUSE | 冻结 dt |
| PAUSE | 页面可见 | 原状态 | 恢复 |

**接口**

```ts
type GameStateId = 'BOOT' | 'SLEEP' | 'WARN' | 'CATCH' | 'RESULT' | 'PAUSE'

interface StateMachine {
  readonly state: GameStateId
  readonly warnIntensity: number  // 0~1，供表现层
  update(dtMs: number, input: InputSnapshot): void
  getSnapshot(): GameSnapshot
}
```

### 4.6 WarnScheduler（预警调度）

**职责**

- 在 `SLEEP` 中倒计时下一次预警
- 在 `WARN` 中推进强度曲线 `intensity(t)`
- 计算当前是否处于 **peak**（可抓窗口）

```ts
interface WarnScheduler {
  onEnterSleep(score: number): void
  updateSleep(dtMs: number): 'idle' | 'fireWarn'
  onEnterWarn(): void
  updateWarn(dtMs: number): {
    intensity: number      // 0~1
    inPeak: boolean
    pastGrace: boolean
    finished: boolean      // 预警自然结束（玩家若已松手则回 SLEEP）
  }
  reset(): void
}
```

**强度曲线建议**

- `0~0.35`：轻动（呼吸乱、鼻子动）→ 不可抓  
- `0.35~warnPeakRatio`：眯眼、哼声 → 不可抓或极低抓概率（MVP：不抓）  
- `≥warnPeakRatio`：危险峰 → 超过 `catchGraceMs` 仍按住则抓  

自然结束：若玩家在 peak 前或 grace 内松开，预警可播完回 `SLEEP`，制造「吓出一身汗」反馈。

### 4.7 Score（计分）

```ts
interface ScoreSystem {
  add(points: number): void
  get current(): number
  commitHighScore(): number   // 返回更新后的最高分
  loadHighScore(): number
}
```

**规则**

- 仅 `SLEEP`（及可选 WARN 非峰值）且 `isActing` 时加分  
- `CATCH` / `RESULT` 不再加分  
- `commitHighScore` 在进入 `RESULT` 时调用一次

### 4.9 Presentation（表现总线）

**职责**：解耦规则与视听；状态机只 `emit`。

| 事件 | 载荷 | 订阅方 |
| --- | --- | --- |
| `state:enter` | `{ state, from }` | Render, Audio, UI |
| `warn:progress` | `{ intensity }` | Render, Audio |
| `score:change` | `{ score, high }` | UI, SceneSkin |
| `catch` | `{ score }` | Render, Audio, UI |
| `session:reset` | `{}` | 全体表现 |

```ts
type GameEvent =
  | { type: 'state:enter'; state: GameStateId; from: GameStateId }
  | { type: 'warn:progress'; intensity: number }
  | { type: 'score:change'; score: number; high: number }
  | { type: 'catch'; score: number }
  | { type: 'session:reset' }

interface PresentationBus {
  emit(e: GameEvent): void
  on(type: GameEvent['type'], fn: (e: GameEvent) => void): () => void
  flush(): void  // 若采用帧末批量
}
```

### 4.10 Render + SceneSkin（渲染与场景）

**Render**：管理画布尺寸、清屏、调用当前 Skin、绘制角色表情层。  

**SceneSkin（策略接口）**：场景差异全部收口于此。

```ts
type FaceStage = 'deepSleep' | 'lightStir' | 'almostAwake' | 'caught'

interface SceneSkin {
  id: 'fridge' | 'alarm' | 'ppt'
  mount(layer: unknown): void
  setFace(stage: FaceStage, intensity: number): void
  setActing(acting: boolean): void          // 冰箱门开合、抽食物
  onScore(score: number): void                // 食物堆叠等
  playCatch(): Promise<void> | void           // 扑脸动画
  draw(ctx: CanvasRenderingContext2D, t: number): void
}
```

**表情映射**

| `warnIntensity` | FaceStage |
| --- | --- |
| 0 且 SLEEP | `deepSleep` |
| `(0, 0.35)` | `lightStir` |
| `[0.35, peak)` | `almostAwake` |
| CATCH | `caught` |

**MVP Skin**：`FridgeSkin`（偷冰箱）。

### 4.11 Audio（音频）

```ts
interface AudioModule {
  unlock(): void
  setMuted(muted: boolean): void
  isMuted(): boolean
  playSleepLoop(): void
  stopSleepLoop(): void
  playWarn(intensity: number): void
  playCatch(): void
  playUi(name: 'start' | 'retry' | 'click'): void
}
```

**绑定建议**

| 状态/事件 | 音频 |
| --- | --- |
| 进入 SLEEP | 呼噜 loop on |
| WARN 进度 | 间歇哼声，强度越高越密/越高 | 
| CATCH | 停止 loop，播惊吓 one-shot |
| 静音 | 全部 gain=0，逻辑不变 |

### 4.12 UI（界面）

**层级**

1. HUD：标题、当前分、最高分、静音  
2. ActZone：全屏或下部大热区（可半透明提示手势）  
3. Overlay：BOOT 开始、RESULT 结算（分数 + 再来一次）  

```ts
interface UIModule {
  sync(snapshot: GameSnapshot): void
  showBoot(): void
  showResult(score: number, high: number, isNew: boolean): void
  hideOverlay(): void
}
```

**零文案**：BOOT 可用「按住」手势动效，不写规则长文。

## 7. 模块 ↔ 需求追溯

| 需求（摘要） | 模块 |
| --- | --- |
| 状态机 SLEEP/WARN/CATCH/RESULT | `StateMachine` |

## 8. 实现优先级（对接需求里程碑）

| 阶段 | 模块范围 | 完成定义 |
| --- | --- | --- |
| M0 灰盒 | App, Config, Input, Session, StateMachine, WarnScheduler, Score, 极简 Render/UI | 色块可玩，张力环可调 |
| M1 表情音效 | Presentation, Audio, FridgeSkin 表情 4 档 | 预警可读、惊吓有刺点 |
| M2 包装 | UI 完整、Storage、移动适配、静音 | 可给外人试玩链接 |
| M3 扩展 | Difficulty, Share, 新 Skin | 传播与长尾 |

## 9. 风险与模块对策

| 风险 | 对策 |
| --- | --- |
| 手感难调 | 全部进 `Config`；M0 先做屏幕参数面板（开发期） |
| 音效被浏览器拦截 | `Audio.unlock` 绑首次指针事件 |
| 换皮牵动逻辑 | 强制 `SceneSkin` 接口，禁止在状态机写冰箱细节 |
| IP 替换角色 | 只改 Skin / 文案 / storage key，核心模块不动 |

---

## 10. 结论

MVP 以 **`StateMachine` + `WarnScheduler` + `Input`** 为规则三角，以 **`SceneSkin` + `Audio` + `UI`** 为表现三角，中间用 **`PresentationBus`** 连接。  

下一步建议：按本设计进入 **M0 灰盒编码**（可先单文件，按模块注释分区），优先跑通状态转移与预警抓捕判定。
