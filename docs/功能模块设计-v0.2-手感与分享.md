## 1. 模块增量总览

```
StateMachine ──emit──► bus
    │  dodge:success / streak:change / run:stats
    ▼
StreakSystem（新）     NearMissFx（新，表现）
    │                        │
    ▼                        ▼
GameSnapshot 扩展      UI toast + Audio.playNearMiss
                              │
ResultOverlay ◄── ShareCard（新）──► download / navigator.share
```

| 模块 | 变更类型 | 职责 |
| --- | --- | --- |
| `StreakSystem` | 新增 | 连击计数、本局峰值、倍率查询 |

| `GameSnapshot` / `GameEvent` | 扩展 | 暴露 streak、maxStreak、isNewRecord、nearMissPulse |
| `Config` | 扩展 | 倍率阈值、near-miss 时长 |
| `Audio` | 扩展 | `playNearMiss()` |
| `UI` | 扩展 | 连击 HUD、好险浮字、结算统计、分享按钮 |

## 2. StreakSystem

```ts
interface StreakSystem {
  streak: number
  maxStreak: number
  resetRun(): void
  onDodgeSuccess(): void
  onCaught(): void
  scoreMultiplier(): number  // streak>=3 → 1.2 else 1
}
```

- 不碰 DOM  
- 由 StateMachine 在「WARN→SLEEP 成功」调用 `onDodgeSuccess`  
- `CATCH` 入口调用 `onCaught`  

---

## 3. 状态机改动点

| 时机 | 动作 |
| --- | --- |
| WARN 存活回 SLEEP | `streak.onDodgeSuccess()`；`bus.emit({ type:'dodge:success', intensity, streak })` |
| 进入 CATCH | `streak.onCaught()` |
| beginRun | `streak.resetRun()` |
| SLEEP 计分 | `rate * streak.scoreMultiplier()` |

Near-miss 不新增状态；用事件驱动表现，避免状态膨胀。

## 4. 事件与快照

```ts
// 新增事件
| { type: 'dodge:success'; intensity: number; streak: number }

// GameSnapshot 新增字段
streak: number
maxStreak: number
isNewRecord: boolean  // RESULT 时有效；进行中可为 false
```

`isNewRecord`：进入 RESULT 时 `score > previousHigh`（commit 前比较）。

## 5. ShareCard

```ts
interface ShareCardInput {
  score: number
  highScore: number
  maxStreak: number
  isNewRecord: boolean
  characterUrl: string  // sleep 或 scare 小图
}

interface ShareCard {
  render(input: ShareCardInput): Promise<Blob>
  shareOrDownload(blob: Blob, filename: string): Promise<void>
}
```

- 尺寸建议 720×1280  
- 绘制：夜厨底色 + 标题 + 大号分数 + 次要信息 + 角色  
- `shareOrDownload`：试 `navigator.share({ files })`，失败则 `<a download>`
